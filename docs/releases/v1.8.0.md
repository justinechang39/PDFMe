# PDFMe 1.8.0

- Browse printed sides in a horizontal thumbnail strip under the large preview. Click any thumbnail to jump to it.
- Use the grid button to see more sides at once, then click a tile to return to the large preview.
- Previous and next wrap between the first and last sides. The strip follows the selected side.
- Thumbnails reflect custom page ranges, pages per side, copies, grayscale, and blank duplex backs. Select a PDF to browse its printed sides.
- Small thumbnails render in the background with a bounded cache and cancellation, without producing full print-resolution images.

Built locally for Apple silicon and Intel Macs running macOS 13 or later. Download **PDFMe-macOS-universal.zip**, unzip, and move PDFMe into Applications. Existing installations can use **Check for Updates**. Saved templates and preferences are preserved; unsent files in the queue clear when the app quits.

Verified locally using composed-output pixel comparisons, wraparound and selection tests, cache/concurrency/cancellation tests, queue and simulated-printer checks, and narrow-layout snapshots. No physical printing. GitHub Actions remains disabled.
