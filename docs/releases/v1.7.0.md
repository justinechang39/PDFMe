# PDFMe 1.7.0

- Print selected pages from each PDF. Choose **Pages → Custom** and enter ranges such as `1-15, 21-30` or `21-end`.
- See selected page counts and an accurate sheet preview. Ranges follow documents between groups and work with duplex, pages per side, and collated copies.
- Invalid ranges block printing; **All** restores the complete document. Page numbers refer to positions in the PDF, starting at 1.
- Fix the Copies field: clear the number and type a replacement normally. Invalid or empty edits block printing until corrected or restored when you leave the field.

Built locally for Apple silicon and Intel Macs running macOS 13 or later. Download **PDFMe-macOS-universal.zip**, unzip, and move PDFMe into Applications. Existing installations can update through **Check for Updates**. Saved templates and preferences are preserved; queued files are held only until the app quits.

Validation: offline print composition, preview, group sequencing and simulated IPP checks, plus real SwiftUI/AppKit copies-field editing checks. No physical jobs submitted. GitHub Actions remains disabled.
