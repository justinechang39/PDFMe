## Download and install

Download **PDFMe-macOS-universal.zip** below (Apple silicon and Intel; macOS 13 or later). Unzip it, move **PDFMe.app** into **Applications**, and open it. The GitHub **Source code** downloads are for developers, not installation.

PDFMe is not Apple-notarized yet. If macOS blocks the first launch, open **System Settings → Privacy & Security → Open Anyway** after trying to launch it.

PDF printing needs no extra software. For DOCX-to-PDF conversion, install LibreOffice separately. Select an installed printer in PDFMe and configure your print templates. Enable the Finder extension through PDFMe’s Settings if you want the top-level right-click action.

## New in 1.6.0

- Automatic updates through Sparkle, downloaded from GitHub Releases. Turn them off in Settings or use **Check for Updates…** whenever you want.
- Cryptographically signed update feeds and downloads, verified before extraction.
- Update restarts are blocked while documents are queued or processing.
- One universal download for Apple silicon and Intel.
- Includes the desktop grouped print queue, Finder right-click integration, per-document copies, previews, and the multi-group printing fixes from 1.5.4.

Install this release manually once to enable future in-app updates. Versions before 1.6.0 do not contain an updater. Saved templates and preferences survive updates.

Built and tested locally. GitHub Actions remains disabled. Printer tests are simulated; the updater is tested using isolated apps, including rejection of tampered updates.
